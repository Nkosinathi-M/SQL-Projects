# Student Management System (SQL)

## Overview

This project is a relational database built using SQL to manage students, lecturers, courses, enrollments, and academic results.

## Features

- Student records
- Lecturer records
- Departments
- Courses
- Enrollments
- Results
- SQL joins
- Aggregate queries
- Views
- Indexes
- Triggers

## Technologies

- SQL
- Oracle Database (MySQL)
- Git
- GitHub
